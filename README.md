# How to Play
There are two judgment circles marked with their keybinds.
Colored circles will bounce toward the judgment circles. Different circles require different actions:
- Blue circles require you to press the appropriate key at the correct time.
- Red circles require you to release at the correct time.
- White circles are untimed and only require you to be pressing the correct key when they hit the judgment circle.
